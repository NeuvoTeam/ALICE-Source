# ALICE card 8i — un-shadow the mono fallback: the source edit (ONE line, ONE file)

Working directory: D:\Work\Neuvo\ALICE\Source

## The defect

`app/globals.css` routes the whole mono stack through Next's generated
`--font-geist-mono` variable:

```
--font-mono: var(--font-geist-mono), ui-monospace, SFMono-Regular, Menlo, monospace;
```

Next's value for that variable is `"Geist Mono", "Geist Mono Fallback"`, and the
second face is a metric-adjusted shim — `@font-face{font-family:Geist Mono
Fallback;src:local(Arial);…;size-adjust:134.59%}` — which is *proportional* and
sits ahead of the `ui-monospace` generic keyword. So on the webfont-failure path
the generic keyword never takes effect and `.font-mono` consumers render in
Arial. Measured: with `*.woff2` blocked, 18 of 18 `.font-mono` elements across
three surfaces render proportionally (47.84px/203.22px in the advance test)
instead of monospaced (87.97px/87.97px).

## The edit

In `app/globals.css`, in the `@theme inline` block, change exactly this line:

```css
  --font-mono: var(--font-geist-mono), ui-monospace, SFMono-Regular, Menlo, monospace;
```

into:

```css
  --font-mono: 'Geist Mono', ui-monospace, SFMono-Regular, Menlo, monospace;
```

That is the ONLY change required. Do not touch the line above it
(`--font-sans: 'Geist', 'Geist Fallback';`) and do not touch any other line of
the file, any other file, `app/layout.tsx`, or the font loader call.

## Why this is sufficient (do not "improve" it)

- The emitted `@font-face` for the real face declares the family name
  `Geist Mono` literally, so a literal reference resolves to it.
- The loader call in `app/layout.tsx` keeps `variable: "--font-geist-mono"` and
  `<body>` keeps `${geistMono.variable}`, which is what emits the `@font-face`
  rules and the variable class. Removing the *reference* to the variable does not
  stop the faces being emitted.
- Do NOT add `adjustFontFallback: false` to the loader, do NOT delete the
  `variable:` option, do NOT change `app/layout.tsx`, and do NOT reorder
  `ui-monospace` ahead of `'Geist Mono'` — the real face must still win when it
  loads.
