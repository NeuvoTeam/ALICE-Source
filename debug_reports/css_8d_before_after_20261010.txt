utility rules whose only occurrence was in those files. To attribute any CSS delta rather than
assume it, the same `npm run build` was run twice from this working tree:

  A. BEFORE  — `git checkout HEAD -- components/ui/sidebar.tsx components/ui/carousel.tsx`, build
